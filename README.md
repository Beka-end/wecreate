# Заплатка для WeCreate

Что чинит: эндпоинт `/api/ai` принимал готовый промпт из браузера — то есть
работал как бесплатный Claude для всех желающих, за твой счёт.
Теперь промпты собираются на сервере, а из браузера уходят только данные.

## Что осталось сделать руками — src/App.jsx

Этого файла в папке нет: у меня нет его целиком, а угадывать
недостающее нельзя. Три правки, все мелкие.

**1. Строка импорта в самом верху.** Было:

    import { askAI, reserveAmount, createRequest, ... } from "./api.js";

Стало (`askAI` убрать, добавить две функции):

    import { generateSite, patchSite, reserveAmount, createRequest, checkStatus, redeem, adminCall, saveProject, loadProject, publishSite, checkSlug } from "./api.js";

**2. Функция `applyRequest`.** Удалить блок целиком:

    const prompt = `Ты правишь готовый сайт малого бизнеса...
    ...
    {"look":{...},"data":{...},"reply":"..."}`;

Затем заменить строку:

    const patch = await askAI(prompt);

на:

    const patch = await patchSite(state, q);

**3. Функция `generate`.** Удалить два блока подряд:

    const brief_ = `Вот всё, что рассказал владелец...`;
    const prompt = `Ты копирайтер и арт-директор...`;

Затем заменить строку:

    const parsed = await askAI(prompt);

на:

    const parsed = await generateSite(brief, lang);

Импорты `PALETTES`, `FONTS`, `HEROES` и остальные из `site.js`
не трогай — они по-прежнему нужны для проверки ответа модели
и для панели «Вид».

## Проверка после деплоя

1. Собери сайт как обычно — должно работать точно так же.
2. Консоль браузера (F12), выполнить:

       fetch("/api/ai",{method:"POST",headers:{"content-type":"application/json"},body:JSON.stringify({prompt:"напиши стих"})}).then(r=>r.json()).then(console.log)

   Ответ `{error: "Неизвестное действие"}` — всё встало.
   Пришёл стих — старый файл не заменился.

3. Нажать «Создать сайт» семь раз подряд — на седьмой
   должно появиться «Слишком часто».

## Если сборка упала на импорте

`api/ai.js` импортирует списки палитр из `../src/site.js`.
Если Vercel ругается на этот импорт — значит в `site.js` есть
что-то браузерное. Напиши, вынесем списки в отдельный файл.

## Настройки лимитов

Сверху в `api/ai.js`:

    DAILY_LIMIT        всего обращений к модели в сутки (300)
    IP_GEN_PER_HOUR    «Создать сайт» с одного адреса (6)
    IP_PATCH_PER_HOUR  правок словами с одного адреса (30)

Счётчики живут в памяти — это заплатка, не полноценная защита.
Надёжный вариант требует внешнего хранилища.

## Ещё не закрыто

- **Перебор PIN в кабинете.** Попытки не считаются, четырёхзначный
  код подбирается скриптом за минуты. Доступ к кабинету = бесплатная
  выдача кодов. Чинится в `api/store.js`, ветка `action === "admin"`.
- **Публикация произвольного HTML.** `publishSite` кладёт на твой
  домен всё, что прислал браузер. С валидным кодом можно опубликовать
  что угодно, вплоть до фальшивой страницы оплаты.
- **Код заказа вместо аккаунта.** Потерял код — потерял сайт навсегда.
