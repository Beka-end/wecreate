# WeCreate — публикация на Vercel

Готовый проект: лендинг, генератор сайтов, очередь заявок и кабинет владельца.

## Что нужно завести

1. **Node.js** — https://nodejs.org, версия 18 или новее.
2. **GitHub** — бесплатно.
3. **Vercel** — бесплатно, вход через GitHub.
4. **Ключ Anthropic** — console.anthropic.com → Billing (привязать карту) → API Keys → Create Key. Ключ показывают один раз, начинается на `sk-ant-`. Там же поставьте месячный лимит трат.

## Шаг 1. Проверить у себя

```bash
cd wecreate
npm install
npm run dev
```

Откроется `localhost:5173`. Дизайн и «Перемешать вид» работают сразу; кнопка «Собрать сайт» пока не сработает — серверных функций в этом режиме нет. Полная проверка локально:

```bash
npm i -g vercel
vercel dev
```

## Шаг 2. Залить на GitHub

```bash
git init
git add .
git commit -m "WeCreate"
```

Создайте пустой репозиторий на GitHub и выполните команды, которые он покажет.

## Шаг 3. Подключить хранилище (иначе заявки не сохранятся)

1. vercel.com → ваш проект → вкладка **Storage** → провайдеры баз данных из Marketplace → **Upstash** → **Redis**.
2. Создайте базу на бесплатном тарифе и нажмите **Connect** к проекту.
3. Vercel сам добавит переменные с адресом и токеном — вручную ничего вписывать не нужно.

## Шаг 4. Переменные окружения

Settings → **Environment Variables**:

| Переменная | Значение | Зачем |
|---|---|---|
| `ANTHROPIC_API_KEY` | `sk-ant-...` | тексты сайтов |
| `ADMIN_PIN` | придумайте сами, например `4021` | вход в кабинет |
| `PRICE_KZT` | `2500` | цена, необязательно |

Отметьте все три окружения (Production, Preview, Development). После добавления — **Deployments → ⋯ → Redeploy**, иначе переменные не подхватятся.

## Шаг 5. Проверить

- Открыть адрес проекта, собрать сайт для тестового бизнеса — должны прийти тексты.
- Открыть `ваш-адрес.vercel.app/#kabinet`, ввести PIN — откроется кабинет.
- Отправить тестовую заявку и выдать себе код.

## Если 404

- **404 на `/api/ai` или `/api/store`** — папка `api` не попала в репозиторий. Проверьте: `git ls-files api` должен показать два файла.
- **404 на самом сайте** — в настройках проекта Framework Preset должен быть **Vite**, Output Directory — **dist**.
- **«Не подключено хранилище»** — не сделан шаг 3 или не было Redeploy после подключения.

## Свои настройки

- **Ссылка Kaspi и цена** — `src/App.jsx`, объект `PAY` в самом верху.
- **Палитры, шрифты, раскладки** — `src/site.js`.
- **PIN** — только в переменных Vercel, в коде его нет.

## Свой домен

Settings → Domains → Add. Домен `.kz` покупается у казахстанского регистратора, дальше в его панели прописываются серверы имён Vercel. HTTPS выдаётся автоматически и бесплатно.

## Что делать дальше

1. **Публикация сайтов за клиента.** Сейчас человек скачивает файл и сам несёт его на хостинг. Отдавать готовую ссылку — главная причина, по которой станут платить.
2. **Автопроверка оплаты.** Заявки сверяются руками по уведомлениям Kaspi. Kaspi Pay с API или посредник дают webhook с точной суммой. Нужны ИП и договор.
3. **Ограничение бесплатных сборок.** Генерация стоит вам денег: поставьте лимит вроде трёх сборок с устройства в сутки.
