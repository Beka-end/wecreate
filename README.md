# Заплатка для WeCreate

## Порядок действий

    1. Распаковать содержимое поверх проекта с заменой файлов
    2. В корне проекта выполнить:  node patch-app.mjs
    3. Задеплоить

Скрипт сам внесёт 13 правок в `src/App.jsx` и сохранит оригинал
рядом как `src/App.jsx.bak`. Если что-то пойдёт не так — переименуй
`.bak` обратно, и всё вернётся как было.

## Что в папке

    api/ai.js        заменить целиком — промпты уехали на сервер
    src/api.js       заменить целиком — askAI разделён на два действия
    index.html       заменить целиком — добавлены og-теги
    public/og.jpg    новый файл — превью для WhatsApp
    patch-app.mjs    скрипт правок, после запуска можно удалить

## Что чинится

**Дыра в кошельке.** Раньше `/api/ai` принимал готовый текст запроса
из браузера — то есть работал бесплатным Claude для всех желающих,
за твой счёт. Теперь принимает только данные, промпт собирает сервер.
Плюс лимиты: 6 генераций в час с адреса, 30 правок, 300 в сутки
на весь сервис.

**Демо-текст.** Барбершоп «Пила» стоял в поле как значение — половина
посетителей просто жала кнопку, и ты платил за ненужные сайты. Теперь
поле пустое, демо осталось подсказкой, кнопка неактивна без описания.

**Вечный опрос.** Проверка оплаты дёргала сервер каждые 7 секунд без
конца. Забытая на ночь вкладка — десятки тысяч вызовов. Теперь
останавливается через 20 минут.

**Мелочи.** Разъехавшаяся таблица в кабинете, подпись про кнопку,
которой нет, неиспользуемый импорт, подтверждение при включении
автовыдачи.

## Проверка после деплоя

Собери сайт как обычно — должно работать так же. Затем консоль
браузера (F12):

    fetch("/api/ai",{method:"POST",headers:{"content-type":"application/json"},body:JSON.stringify({prompt:"напиши стих"})}).then(r=>r.json()).then(console.log)

Ответ `{error: "Неизвестное действие"}` — всё встало.
Пришёл стих — старые файлы не заменились.

Ещё: нажать «Создать сайт» семь раз подряд — на седьмой должно
появиться «Слишком часто».

## Если сборка упала на импорте

`api/ai.js` берёт списки палитр из `../src/site.js`. Если Vercel
ругается на этот импорт — значит в `site.js` есть что-то браузерное.
Напиши, вынесем списки в отдельный файл.

## Настройки лимитов

Сверху в `api/ai.js`:

    DAILY_LIMIT        всего обращений к модели в сутки (300)
    IP_GEN_PER_HOUR    «Создать сайт» с одного адреса (6)
    IP_PATCH_PER_HOUR  правок словами с одного адреса (30)

Счётчики живут в памяти инстанса — это заплатка, не полноценная
защита. Надёжный вариант требует внешнего хранилища.

## Что осталось незакрытым

Нужны файлы, которых у меня нет.

**api/store.js**

- Перебор PIN. Попытки не считаются — четырёхзначный код подбирается
  скриптом за минуты, а кабинет позволяет выдавать коды бесплатно.
- Перебор кодов заказа. Тоже без счётчика, плюс разные тексты ошибок
  для существующего и несуществующего кода — по ним отличают
  попадание от промаха.
- reserveAmount без лимита. Уникальных сумм конечное число; скрипт
  забронирует все, и настоящие клиенты не смогут оплатить.
- publishSite кладёт на твой домен любой HTML, присланный браузером.

**src/site.js**

- У сгенерированных сайтов, похоже, нет og-тегов. Главный канал —
  WhatsApp; если превью пустое, эффект «вау за 20 секунд» пропадает
  в самый нужный момент. Имя бизнеса в og:title, первое фото
  в og:image.

**Без файлов**

- Код заказа вместо аккаунта: потерял код — потерял сайт навсегда,
  а у тебя нет ни одного контакта покупателя.
- Оферта, условия возврата и реквизиты продавца. Тут нужен юрист.
